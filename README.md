# bilemio

> **Note:** The source code of bilemio lives in a private repository. This public repo is a
> project overview: what bilemio is, what it does, and how it's built.

**Three games a day, the same puzzle for everyone.** bilemio is an iOS app for Turkish word
and trivia games. Puzzles refresh every day at midnight Türkiye time, and everyone solves the
same puzzle that day.

*Her gün üç oyun, herkese aynı bulmaca.*

## Games

| Game | How it works |
|---|---|
| **Ekle** | The root word is given; stack the right suffixes in the right order. A puzzle unique to Turkish. 5 tries. |
| **Beşlik** | Find the 5-letter word in 6 tries. Green means right spot, yellow means it's in the word but elsewhere. |
| **Abece** | 28 letters, 28 questions, 5 minutes. Every answer starts with that letter. |

## Highlights

- **Neo-brutalist design:** thick borders, hard shadows and isometric tile illustrations.
- Dark and light themes.
- **Turkish Q keyboard** and proper Turkish letter rules (Ç ≠ C, I ≠ İ, Ş ≠ S).
- Game state is saved per day, so you can leave and pick up right where you left off.
- Sign in with Apple and Google *(coming soon)*.
